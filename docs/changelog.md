# 更新日志（历史）

`release-notes.md` 只放当前这一版，会被 CI 整份当发布说明。历史版本记在这里。

## DeepSleep For Windows v0.5.0 - Beta

界面重做，加了临时的「别睡一会儿」。

### 本次更新中做出了下列优化：

- 四张电源卡片改成两列，不再出现第四张孤零零掉到第二行
- 计划设置按「显示 / 睡眠 / 硬盘 / 处理器」分组，不再是十一行数字平铺
- 计划下拉框的选项里已经写了「10 分钟」，右边不再重复一个「分钟」
- 后台服务那一块收成一行，不出问题时不占地方

### 本次更新中添加了下列功能：

- 概览页：当前电源计划、为什么是这个计划、空闲计时和进度条
- 临时不睡觉：概览四个按钮、托盘菜单同一组、命令行 `hold 30` 与 `hold off`
- 一条规则可以加多条条件（星期 / 时间段 / 空闲时长组合）
- 规则优先级，数字大的先执行
- 日志页搜索框与「全部 / 警告 / 错误」筛选，概览页显示最近六条
- `Ctrl+1` 到 `Ctrl+5` 切页，`Esc` 关闭进程选择弹窗

### 本次更新中修复了下列问题：

- 进程选择弹窗没有遮罩、不居中
- 新建规则选「切换电源计划」时计划下拉是空的
